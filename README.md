# PRISMATE

**Jaque mate en todos los colores.**

Ajedrez 3D: un reino de cristal contra un ejército de obsidiana. Juega contra la computadora (5 niveles), aprende desde cero con el tutorial interactivo o reta a un amigo en el mismo dispositivo.

▶ **Juega ahora:** https://gamexic.github.io/prismate/

Funciona directamente en el navegador (necesita WebGL y conexión para cargar librerías y fuentes). Sin instalación.
